BMM Lab Website — 배포용 패키지 (v8.1)

1. Netlify: https://app.netlify.com/drop 에 접속합니다.
2. 이 ZIP 파일의 압축을 풉니다.
3. 압축을 푼 BMM_Lab_Website_Deploy_Ready_v8_1 폴더 전체를 Netlify Drop에 끌어다 놓습니다.
   (index.html이 폴더 최상위에 있어야 합니다.)
4. 발급된 사이트 주소에서 Home / Research / Publications / People / Videos를 확인합니다.
5. 수정할 때는 새 ZIP을 압축 해제해 동일 사이트의 Deploys에 폴더를 다시 배포합니다.

파일 구성
- index.html : 홈페이지 본문, 화면 동작 및 논문/구성원 데이터
- assets/ : 로고, 사진, 핵심기술 이미지 등 22개 파일

주의
- 현재 버전은 정적 홈페이지입니다. 로그인/학생별 편집권한/승인 기능은 운영 준비가 완료되지 않았습니다.
- 영상 4편은 YouTube 외부 페이지로 연결됩니다. 네트워크가 필요합니다.
- 관리자 기능은 별도 구축이 필요하며 이 배포본에서는 작동하지 않는 관리자 링크를 숨겼습니다.
- 논문 및 구성원 개인정보/공개 여부를 공개 전에 검토하세요.
- ChatGPT 내부 미리보기는 정상 동작을 보장하지 않으므로 실제 배포 URL 또는 Chrome에서 확인하세요.
